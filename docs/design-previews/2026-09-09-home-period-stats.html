现状与数据说明

当前首页 Hero 卡只显示一个周期的收支(默认本月,可切「今年/汇总」),上月收支在 Web 端完全看不到。以下三个方案都补齐「今年 + 上月」两组数字,差别只在摆放位置和信息密度。

  • 数据来源:「今年」复用现有 year scope 请求,零新增;「上月」需新增 1 次 analytics?scope=month&period=上月 请求(口径跟随账本记账起始日),失败静默降级,不影响其它卡片。
  • 模拟范围:每个方案都画出「Hero 卡 → 新增内容 → 习惯画像区」的位置关系;Hero 卡为简化还原,虚线框 = 新增部分。
  • 交互预留:卡片点击可跳转交易页按周期筛选(需交易页支持日期参数,本次可不做,先纯展示)。
方案 A 推荐

双周期速览卡 —— Hero 下方并排「上月收支」「今年收支」两张独立卡片

紧跟 Hero 新增一排两张卡(桌面并排 / 手机竖排),每张卡展示该周期的收入、支出、结余和「支出占收入」比例条;上月卡带支出环比,今年卡带月均支出。信息完整、层次清晰,不动现有 Hero 结构。

✓ 两个周期一屏同览,收支/结余/衍生指标都放得下 ✓ 独立卡片,后续可扩展点击跳转、图表 ✕ 首页纵向长度 +1 排,与 Hero 的「今年」切换视角略有信息重合

方案 B

Hero 内嵌对比行 —— 收进 Hero 卡内部,大结余下方一行两枚横条

不新增首页区块,在 Hero 卡内部(收支四宫格与预算 chip 之间)插入两枚横排内嵌卡:上月 / 今年各一条,横向排「收入 · 支出 · 结余」。所有关键收支收敛在首屏 Hero 内,视觉重心不散,但 Hero 变高、单卡信息密度低于方案 A。

✓ 不增加首页区块数,首屏一卡看完 ✓ 与 Hero 现有毛玻璃小卡风格天然统一 ✕ Hero 高度 +约 90px,移动端会更长 ✕ 放不下比例条/环比等衍生指标(空间有限)

方案 C

周期对比表 —— Hero 下方一张紧凑表格卡(上月 / 今年 两行 × 收支三列)

信息密度最高、占地最小的做法:一张「周期对比」表格卡,行=周期、列=收入/支出/结余,可顺带放一行灰色的「全部」(数据已有)做总览。适合喜欢清爽表格风的用户,但少了些「仪表盘氛围感」,衍生指标(环比/月均)只能以小字塞在行内。

✓ 最省空间,一行一个周期,扩展「全部」行零成本 ✓ 数字纵向对齐,对比着看最直观 ✕ 表格观感偏「报表」,与首页卡片风略有割裂
